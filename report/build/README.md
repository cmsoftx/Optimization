# Case study report build

`C_M_Karthik_Optimization_Case_Study_Report.docx` is generated by `build_report.js` (npm `docx`), with figures in `figs/` redrawn by `make_figs_report.py` from `data/outputs/` and `presentation/build/forecast_series.json`. All numbers come from the verified outputs at commit `dc2e9ed` (see `presentation/Presentation_Sources.md`).

```bash
python3 make_figs_report.py /home/user/Optimization figs ../../presentation/build/forecast_series.json
node build_report.js out.docx pages.json   # pages.json holds the index page ranges
```

The PDF is a LibreOffice rendering of the .docx.
